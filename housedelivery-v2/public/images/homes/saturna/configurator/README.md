# Saturna configurator design boards

The 56 final PNG boards provide four Premium and four Signature selections in
each of the seven existing chapters. Filenames in this directory follow the
existing repository convention; Downloads sources are unchanged.

Category, tier, selection number and style below follow the printed image headers.
Kitchen and wardrobe retain Contemporary Luxe / Scandi Light; the ensuite retains
its own four directions. The remaining chapters use Contemporary Cool / Scandi Natural.

Source correction: `Additional Images/Saturna - Interior Doors & Details - Premium 4 - Modern Earth.png`
prints **Window Coverings — Premium 4 — Modern Earth**. Its repository destination
is `Saturna_07_Window-Coverings_Premium-4_Modern-Earth.png`.
