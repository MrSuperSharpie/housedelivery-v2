Checkpoint: 026c1e3, existing Concierge feature branch. No production/main changes.

## Diagnosis

The reported question contains “conducts cold way faster than wood”. The shared comparison classifier matched “than” and “fast” as an unsupported construction-speed claim. Normalization added the closed system-comparison record; controlled composition then displayed its quotation/comparison limitation instead of explaining thermal bridging. This is an application routing/evidence-boundary defect, not evidence of a provider failure.

## Narrow correction

Exclude explicitly described physical heat-transfer speed from the construction-speed metric. Other speed/commercial claims in the same question remain bounded. Independent wall-mechanism requests retain their own public answer alongside a parent price comparison.

Add one curated general building-science record to the existing server-controlled record mechanism. Its authority is explicitly separate from approved company specifications. It explains effective whole-wall R-value, continuous exterior insulation, attachment/junction detailing and air/vapour/humidity/climate considerations. It does not claim that House Delivery uses a particular wall assembly, material, attachment or thickness, has a verified R-value, or guarantees no condensation. Those project-specific details require confirmation. No unrestricted retrieval, additional model/reviewer, private source or maintainer document is exposed to runtime.
