## Diagnosis and changes

The parent already used genuine structured LLM extraction, composition and a
separate support review. The improvement addresses sparse topic-only context,
broad routing into fixed replies and all-or-nothing fallback behavior, rather
than replacing a fixed FAQ. Existing safeguards remain in the same request path.

Intent extraction selects handbook sections by meaning and authenticated retained
context. Retrieval supplies concise company context plus up to six other complete
sections alongside controlled facts/models. Related topics can be combined for
mixed questions. Only selected public data is sent, never an archive or ledger.

The composer answers before suggesting a next step and permits grounded,
preference-based explanations. It need not ask a question or attach links on
every turn. Commercial/numeric controls remain; budget-scope explanations and
mixed manufacturing/Look Book/builder questions can use natural synthesis.
Household priorities join signed session memory. Explicit initial phase counts
and a corrected maximum using already stated units retain their distinct meaning.

Each proposed passage still passes deterministic claim guards and a separate
support review. Review covers all passages and qualifications. Independently
supported passages can survive another passage's rejection; no new answer is
generated by the reviewer. Non-sensitive rejection codes and selected section,
model and evidence IDs are visible only through existing Preview staff HMAC
evaluation access. Raw prompts, answers and private-source mappings are not
added to ordinary logs. Provider failures remain failures, not quality passes.

UI, four journeys, launcher, mobile panel, navigation, Studio, Look Books, pricing
data, consent forms, email delivery, artwork/video and all non-Concierge pages are
unchanged. Existing session/cookie/origin checks, forged-history rejection, public
rate limits, consent and truthful delivery handling are preserved.

The repository is public. The initial feature checkpoint included editorial source
URLs; the corrected feature commit excludes the whole local package. No private
source document bodies, correspondence, credentials or customer records were
imported. Rewriting this task's branch does not guarantee removal from GitHub
commit caches; that limited exposure is disclosed in the review report.
