## Evidence Validation Boundary

This sprint improves UI targeting language only. Evidence attachment now tells inspectors that files, notes, photos, and videos must support the exact checklist item, and that an attached file does not prove the evidence is substantively correct.

Future Pro Audit Sprint 02 should handle deeper typed/governed evidence validation, including item-specific evidence schemas, governed N/A eligibility, and stronger review semantics for whether attached evidence satisfies the checklist item.
