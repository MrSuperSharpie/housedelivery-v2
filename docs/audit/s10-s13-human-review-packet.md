> This packet reproduces the S10–S13 checklist content **exactly as drafted** — nothing here is changed.
> It is for a practicing BC inspector / reviewer to mark each item **Accept / Revise / Unsure**.
> BCBC and VBBL are **identical for S10, S11, and S13**; VBBL differs from BCBC only at **S12** (one extra
> Vancouver Step Code item). "Short purpose" = the item's `requirement_text`; "Code reference" =
> `legal_reference`. Item counts: S10 4/4 · S11 4/4 · S12 4 (BCBC) / 5 (VBBL) · S13 5/5.
