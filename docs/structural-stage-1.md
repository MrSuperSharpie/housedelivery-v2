# SiteLine Master Inspection Content Specification

## Permit Family: Structural

### Stage Sequence Used in This Draft
1. **Stage 1: Project Setup and Jurisdiction Check**
2. **Stage 2: Footings & Foundation / First Field Inspection**

This structure keeps Stage 1 as a **pre-field validation** stage and moves the first physical field inspection into Stage 2.

---

# Structural — Stage 1: Project Setup and Jurisdiction Check

## Stage Purpose
Confirm the project identity, governing authority, code path, permit scope, and foundational review context before any field inspection activity proceeds. This stage protects the integrity of the inspection record by ensuring the inspector is working against the correct job, permit family, jurisdictional rules, and submitted documentation set.

## Stage Operating Principle
This is primarily a **document and context verification stage**. In most cases, the inspector is validating builder-uploaded records already in the file. Stage 1 should therefore rely mainly on **verification of existing project documents**, not fresh field uploads by the inspector, unless a material gap or discrepancy requires additional supporting evidence.

---

## Container S01-01 — Project Address and Legal Description

### Purpose
Confirm that the inspection is being performed against the correct property, permit file, and legal parcel record before field execution proceeds.

### What the Inspector Must Check
- Civic address matches the permit and supporting documents.
- Legal description matches the submitted permit package, drawings, survey, or site documentation.
- Project identity is consistent across all uploaded records.
- No mismatch exists between site address, permit reference, and supporting documentation.

### Pass When
- The civic address is correct and consistent across the record set.
- The legal description is present and matches the permit package.
- No material discrepancy exists in the project identity.

### Fail When
- The civic address conflicts with the permit or submitted documents.
- The legal description is missing, incomplete, or inconsistent.
- Supporting records identify a different parcel, lot, or project location.
- The mismatch creates uncertainty about the correct inspection file.

### Pending When
- Additional documentation is required before confirming the project identity.
- Submitted records are incomplete but may be clarified quickly.

### Inspector Notes Guidance
Record the address reviewed, legal description reviewed, documents checked, permit reference, and any discrepancy or confirmation.

### Required Evidence / Documents
- Builder-uploaded permit document or permit cover page.
- Builder-uploaded site plan, survey, or drawing showing the project address and legal description.

### Optional Evidence / Documents
- Supporting correspondence.
- Authority comments.
- Additional routing or review notes.
- Inspector-uploaded supplemental evidence only if a discrepancy must be documented.

### AHJ / Jurisdiction Notes
Capture any jurisdiction-specific naming differences, civic addressing conventions, legal parcel references, or authority-imposed project identifiers.

---

## Container S01-02 — Governing Authority, Code Path, and Jurisdiction Overlay

### Purpose
Confirm the correct governing authority, permit issuing body, code path, code edition, and any jurisdiction-specific overlay that affects structural review before field execution begins.

### What the Inspector Must Check
- Correct AHJ has been identified.
- The permit was issued or routed through the expected authority.
- Applicable code family is correctly identified.
- Code edition in force for the permit is understood.
- Local amendments, municipal overlays, or authority bulletins that affect this project are known.
- The project is not subject to a different municipality, regional district, or First Nation land office than stated.

### Pass When
- The governing authority is correctly identified.
- Permit routing aligns with the AHJ shown in the project documents.
- Code path and code edition are clearly identified.
- Any local amendments or adopted variations are known and recorded.
- No unresolved jurisdictional or code ambiguity exists.

### Fail When
- The wrong AHJ appears to be associated with the project.
- Permit routing is inconsistent with the site location or project record.
- The wrong code edition appears to have been used.
- No governing code path can be identified from the project record.
- Local amendments likely apply but are not reflected in the file.

### Pending When
- Authority confirmation is required on jurisdiction, code edition, or amendment applicability.
- The permit record is incomplete but can likely be clarified.

### Inspector Notes Guidance
Record the identified AHJ, permit issuing body, review path, governing code, code edition, and any known local overlay or exception.

### Required Evidence / Documents
- Builder-uploaded permit document showing issuing authority.
- Builder-uploaded application, code summary, or routing document identifying governing code basis and authority.

### Optional Evidence / Documents
- Municipal bulletins.
- AHJ circulars.
- Consultant code notes.
- Inspector-uploaded supplemental evidence only if a code-path or jurisdiction discrepancy must be documented.

### AHJ / Jurisdiction Notes
Use this container to capture municipality-specific, regional district, or First Nation authority conditions that materially affect the structural inspection path.

---

## Container S01-03 — Project Type, Building Type, and Structural Scope Classification

### Purpose
Confirm the project type, building type, occupancy context, and structural review scope so the correct downstream checklist path is used.

### What the Inspector Must Check
- Project type is correctly identified (new build, addition, renovation, tenant improvement, change of occupancy, etc.).
- Building type is identified accurately (house, duplex, townhouse, multifamily, commercial, mixed-use, etc.).
- Occupancy or use context is understood where it affects structural requirements.
- Structural scope is correctly classified.
- The structural permit family is actually applicable to this job.
- The next-stage inspection path aligns with the nature of the work.

### Pass When
- Project type is clearly identified.
- Building type and occupancy/use context are consistent across the record set.
- Structural scope is correctly classified.
- The project fits the selected structural checklist path.

### Fail When
- Project type is misclassified.
- Building type is inconsistent across documents.
- Occupancy/use context suggests a different review standard than the one applied.
- Structural scope appears materially different from the posted job.
- The selected checklist path is not appropriate to the actual work.

### Pending When
- Additional drawings or permit notes are needed to determine the exact project type, building type, occupancy context, or structural scope.

### Inspector Notes Guidance
Record the project type, building type, occupancy/use context, structural work category, and any reason the selected structural path is or is not appropriate.

### Required Evidence / Documents
- Builder-uploaded permit description or scope-of-work statement.
- Builder-uploaded drawings, design notes, or application form showing building type and structural scope.

### Optional Evidence / Documents
- Builder scope summary.
- Consultant notes.
- Authority comments.
- Inspector-uploaded supplemental evidence only if a misclassification must be documented.

### AHJ / Jurisdiction Notes
Note any local trigger thresholds or permit-family distinctions that affect whether this project falls into structural review.

---

## Container S01-04 — Site Record, Drawings, and Revision Package Readiness

### Purpose
Confirm that the base site record, structural drawing package, and revision context are current, identifiable, and sufficient for the first field inspection stage.

### What the Inspector Must Check
- Site plan or survey is present where required.
- Setback, property line, and siting information are available where required.
- Structural drawings are present where required.
- Revision dates and identifiers are visible.
- The inspector is working from the latest known issue/revision set.
- No obvious mismatch exists between the active permit record and the structural drawing set.
- There is enough site and drawing context to proceed without material ambiguity.

### Pass When
- A sufficient site plan, survey, or equivalent record is available.
- Structural drawing package is available and current enough for the stage.
- Revision identifiers are visible and coherent.
- No major siting, revision, or document-set ambiguity remains.

### Fail When
- Required site plan or survey information is absent.
- Required structural drawings are missing.
- Revision history is unclear or inconsistent.
- Multiple drawing versions create unresolved uncertainty.
- The absence of the base record undermines reliable review.

### Pending When
- Site documentation or revised drawings are expected but not yet uploaded.
- The current set may be sufficient only after clarification.

### Inspector Notes Guidance
Record what site record and drawing package were reviewed, what revision identifier/date was used, and any missing information affecting confidence.

### Required Evidence / Documents
- Builder-uploaded site plan and/or survey, where applicable.
- Builder-uploaded permit drawing set showing structure location on site.
- Builder-uploaded structural drawing package with revision identifiers, where applicable.

### Optional Evidence / Documents
- Topographic plan.
- Civil plan.
- Revision log.
- Consultant correspondence.
- Inspector-uploaded supplemental evidence only if a document-set discrepancy must be documented.

### AHJ / Jurisdiction Notes
Capture any municipality-specific setback, frontage, lane, easement, siting, stamped-set, or revision-tracking requirement that affects structural readiness.

---

## Container S01-05 — Registered Professional and Permit Coordination Flags

### Purpose
Determine whether registered professional involvement and related permit coordination are required so the structural pathway is not assessed in isolation where coordination is necessary.

### What the Inspector Must Check
- The project triggers professional design or field review requirements where applicable.
- Relevant registered professional involvement is identified in the file.
- Related permit scopes are identified where relevant.
- The project is not missing obvious coordinated permit streams that materially affect readiness.
- The project record does not suggest required professional oversight or trade coordination that is absent.

### Pass When
- Required professional involvement is either not triggered or clearly documented.
- Related permit coordination needs are either not applicable or clearly identified.
- No unresolved professional or trade coordination issue prevents proceeding.

### Fail When
- Registered professional involvement appears required but is absent or undocumented.
- Missing or conflicting trade permit coordination materially affects project readiness.
- The file suggests unsupported structural design responsibility or incomplete permit context.

### Pending When
- Additional consultant, permit-office, or builder clarification is required to confirm whether professional involvement or permit coordination is triggered.

### Inspector Notes Guidance
Record whether professional involvement is required, what triggered that determination, what related permit families are involved, and whether their status affects structural readiness.

### Required Evidence / Documents
- Builder-uploaded structural drawings or design notes indicating professional responsibility where applicable.
- Builder-uploaded permit or application record identifying consultant involvement and related scopes.

### Optional Evidence / Documents
- Letters of assurance.
- Field review commitments.
- Consultant coordination notes.
- Permit-office comments.
- Inspector-uploaded supplemental evidence only if a coordination or assurance deficiency must be documented.

### AHJ / Jurisdiction Notes
Capture local triggers that elevate the project into registered professional, assurance-letter, or coordinated trade-permit territory.

---

## Stage Completion Rule
Structural Stage 1 is complete only when:
- all required containers are resolved,
- all required builder-provided documents needed for verification are present,
- any inspector-uploaded supplemental evidence required to document a discrepancy has been attached,
- no unresolved dependency remains,
- the structural inspection path is confirmed as valid for downstream field execution.

## Stage Outcome
When Stage 1 is complete, the inspector has established:
- the correct project identity,
- the correct governing authority and code path,
- the correct structural scope and classification,
- the correct foundational document and revision context,
- and the readiness to proceed into field-stage structural inspection.

# Structural — Stage 2: Footings & Foundation / First Field Inspection

## Stage Purpose
Confirm that excavation, bearing preparation, formwork, reinforcement, geometry, embedments, and related foundation conditions are ready for structural approval before placement proceeds or before the next structural stage advances.

## Stage Operating Principle
This is the first true **field inspection stage**. The inspector is now validating physical site conditions against the approved permit and structural record. Stage 2 should rely on direct site observations, professional judgment, and supporting field evidence captured at the time of inspection.

---

## Container S02-01 — Site Condition, Layout, and Inspection Readiness

### Purpose
Confirm that the site is ready for a meaningful foundation inspection and that the inspector is reviewing the correct stage at the correct time.

### What the Inspector Must Check
- Excavation or footing area is accessible for inspection.
- Site condition allows meaningful observation of the work.
- Work has not advanced beyond the stage intended for review.
- The footing/foundation area being inspected matches the approved layout and intended inspection scope.

### Pass When
- The site is accessible and safe enough for inspection.
- The inspected area is clearly identifiable.
- The work remains at the correct hold point for this stage.

### Fail When
- The site is not reasonably inspectable.
- The wrong area or wrong stage appears to be presented.
- Work has advanced beyond the intended inspection hold point in a way that compromises review.

### Pending When
- Access, preparation, or timing issues temporarily prevent a reliable inspection.

### Inspector Notes Guidance
Record site condition, accessibility, whether the correct hold point was presented, and any reason the stage was or was not ready for inspection.

### Required Evidence / Documents
- Inspector-captured site photos showing the inspected area and readiness condition.

### Optional Evidence / Documents
- Site overview video.
- Builder clarification notes.
- Layout or staging photos.

### AHJ / Jurisdiction Notes
Capture any authority-specific hold-point requirement or inspection-timing condition relevant to foundation review.

---

## Container S02-02 — Excavation Depth, Bearing Surface, and Base Preparation

### Purpose
Confirm that excavation and bearing preparation appear consistent with the intended foundation design and are suitable for structural review at this stage.

### What the Inspector Must Check
- Excavation has reached the intended level for the footing/foundation work being reviewed.
- Bearing surface appears prepared, stable, and appropriate for the intended work.
- Base condition is not obviously compromised by loose material, standing water, frost, organic material, or other visible concerns.
- Any special preparation requirements noted in the file are reflected in the field condition.

### Pass When
- Excavation and base preparation appear complete enough for the footing/foundation stage.
- Bearing surface shows no obvious visible condition that undermines readiness.

### Fail When
- Excavation is incomplete or inconsistent with the intended footing level.
- Bearing surface shows visible instability or unsuitable preparation.
- Obvious adverse conditions materially affect confidence in readiness.

### Pending When
- Additional preparation is underway and can likely be completed quickly.
- Specialist input or supporting documentation is required before confirming readiness.

### Inspector Notes Guidance
Record excavation condition, observed base preparation, visible concerns, and any limitation on confidence.

### Required Evidence / Documents
- Inspector-captured photos of excavation and bearing areas.

### Optional Evidence / Documents
- Geotechnical notes.
- Builder correction photos.
- Video of site conditions.

### AHJ / Jurisdiction Notes
Capture any local requirement or geotechnical trigger affecting footing excavation or bearing acceptance.

---

## Container S02-03 — Footing Geometry, Dimensions, and Location

### Purpose
Confirm that footing size, layout, and location appear consistent with the approved foundation intent.

### What the Inspector Must Check
- Footing width, depth, and general configuration appear consistent with the approved record.
- Footings are located where the design intends them to be.
- Step footings, thickened areas, pads, or special footing conditions are present where required.
- No obvious location or dimension mismatch is visible.

### Pass When
- Observed footing geometry and location appear consistent with the approved intent.
- No material visible discrepancy is identified.

### Fail When
- Footing size, location, or configuration appears materially inconsistent.
- Required footing elements appear missing or incorrectly formed.

### Pending When
- Minor setup or layout clarification is still required before a reliable decision can be made.

### Inspector Notes Guidance
Record the footing condition reviewed, observed geometry/location, and any visible discrepancy or confirmation reference.

### Required Evidence / Documents
- Inspector-captured photos showing footing layout and representative dimensions or configuration.
- Builder-provided foundation drawing or detail already in the project file.

### Optional Evidence / Documents
- Additional measurement photos.
- Marked-up drawing reference.
- Builder clarification notes.

### AHJ / Jurisdiction Notes
Capture any local footing geometry requirement or siting overlay affecting compliance assessment.

---

## Container S02-04 — Reinforcement Placement and Continuity

### Purpose
Confirm that reinforcement appears present, placed, and supported in a manner consistent with the intended footing/foundation design.

### What the Inspector Must Check
- Required reinforcing steel is present where expected.
- Bar size, spacing, laps, bends, and continuity appear generally consistent with the approved record where observable.
- Reinforcement is supported adequately and not obviously displaced.
- Special reinforcing requirements appear present where required.

### Pass When
- Reinforcement is present and generally consistent with the approved intent.
- No material visible deficiency in placement or continuity is identified.

### Fail When
- Required reinforcement appears missing, materially incomplete, or clearly inconsistent.
- Placement or continuity issues materially affect structural confidence.

### Pending When
- Reinforcement work is still in progress and can likely be completed before sign-off.
- Visibility limits prevent a reliable final decision without additional clarification.

### Inspector Notes Guidance
Record observed reinforcement condition, any visible bar placement or continuity issue, and any limitation on the review.

### Required Evidence / Documents
- Inspector-captured photos of reinforcing steel in place.

### Optional Evidence / Documents
- Close-up reinforcement photos.
- Shop drawing reference.
- Builder correction evidence.

### AHJ / Jurisdiction Notes
Capture any local reinforcement inspection expectation, including requirements for visibility before placement.

---

## Container S02-05 — Clearance, Cover, and Separation Conditions

### Purpose
Confirm that reinforcement and footing/foundation elements maintain required visible clearances, cover conditions, and separations where these can be assessed in the field.

### What the Inspector Must Check
- Reinforcement is not visibly resting directly on unsuitable surfaces where cover/support is required.
- Required spacing or separation appears maintained where observable.
- Visible clearance conditions do not suggest an obvious non-compliance.

### Pass When
- Clearance, cover, and separation conditions appear adequate based on field observation.
- No obvious visible deficiency is identified.

### Fail When
- Reinforcement or footing components show visible clearance or cover deficiencies.
- Separation conditions appear materially non-compliant.

### Pending When
- Final support or positioning is still being completed before concrete placement.

### Inspector Notes Guidance
Record observed cover/support condition, any visible deficiency, and any correction required before proceeding.

### Required Evidence / Documents
- Inspector-captured photos showing support, clearance, and cover conditions where applicable.

### Optional Evidence / Documents
- Detail photos.
- Builder correction photos.

### AHJ / Jurisdiction Notes
Capture any local expectation for documented reinforcement support or pre-pour visibility.

---

## Container S02-06 — Formwork, Alignment, and Dimensional Stability

### Purpose
Confirm that formwork appears adequately set, aligned, and stable enough to support the intended footing/foundation placement.

### What the Inspector Must Check
- Formwork is in place where required.
- Alignment appears consistent with the intended footing or foundation shape.
- Bracing and stability appear adequate for the visible condition.
- No obvious visible distortion or instability is present.

### Pass When
- Formwork appears properly assembled and stable.
- Alignment and shape appear consistent with the intended work.

### Fail When
- Formwork is incomplete, visibly unstable, or materially misaligned.
- Visible conditions create reasonable concern regarding dimensional reliability.

### Pending When
- Final bracing or alignment is still being completed before the stage can be signed off.

### Inspector Notes Guidance
Record formwork condition, visible alignment/stability observations, and any correction required.

### Required Evidence / Documents
- Inspector-captured photos of formwork condition and representative alignment.

### Optional Evidence / Documents
- Detail photos of bracing or corners.
- Builder correction evidence.

### AHJ / Jurisdiction Notes
Capture any local hold-point or pre-pour requirement affecting formwork acceptance.

---

## Container S02-07 — Embedded Items, Anchor Elements, and Service Coordination

### Purpose
Confirm that embedded items, anchors, sleeves, or coordinated penetrations required at the foundation stage are present or prepared as required.

### What the Inspector Must Check
- Required embedded items or anchor elements are present where applicable.
- Coordinated service penetrations or sleeves expected at this stage are identified.
- No obvious omission of critical embedded or coordinated element is visible.

### Pass When
- Required embedded or coordinated items appear present and appropriately located where observable.
- No material visible omission is identified.

### Fail When
- Required embedded or coordinated elements appear missing or clearly misplaced.
- Visible omissions would materially affect downstream work or compliance.

### Pending When
- Final embedded or coordinated items are still being installed before sign-off.

### Inspector Notes Guidance
Record what embedded or coordinated items were reviewed and whether any omission or placement concern was identified.

### Required Evidence / Documents
- Inspector-captured photos of embedded items, anchors, sleeves, or coordinated locations where applicable.

### Optional Evidence / Documents
- Detail photos.
- Coordination sketches.
- Builder clarification notes.

### AHJ / Jurisdiction Notes
Capture any local requirement affecting anchor placement, sleeves, or coordination hold points.

---

## Container S02-08 — Water, Drainage, and Adverse Site Condition Flag

### Purpose
Identify visible water, drainage, erosion, or adverse site conditions that materially affect confidence in footing/foundation readiness.

### What the Inspector Must Check
- Standing water, runoff, instability, erosion, or saturated conditions are not visibly undermining the inspected area.
- Site condition does not obviously compromise footing/foundation preparation.
- Temporary controls, where required, appear adequate for the current stage.

### Pass When
- No material visible water or adverse site condition undermines confidence in readiness.
- Site condition appears acceptable for the stage being reviewed.

### Fail When
- Water, drainage, erosion, or similar adverse conditions materially affect the footing/foundation area.
- Site condition visibly compromises readiness or reliability.

### Pending When
- Temporary correction or stabilization is in progress and may restore readiness quickly.

### Inspector Notes Guidance
Record any observed water, drainage, or adverse site condition and whether it affects inspection outcome.

### Required Evidence / Documents
- Inspector-captured photos of the affected area where adverse conditions exist.

### Optional Evidence / Documents
- Video of water or drainage condition.
- Builder correction evidence.
- Geotechnical follow-up notes.

### AHJ / Jurisdiction Notes
Capture any local condition or seasonal requirement affecting acceptance under wet, unstable, or adverse site circumstances.

---

## Container S02-09 — Foundation Stage Approval Readiness

### Purpose
Confirm whether the footing/foundation stage is ready to proceed beyond the hold point based on the totality of observed conditions in Stage 2.

### What the Inspector Must Check
- All prerequisite foundation observations in this stage have been resolved.
- No unresolved visible deficiency remains that should prevent advancement.
- The footing/foundation work is ready for approval, correction, or hold based on field evidence.

### Pass When
- Stage 2 observations support progression beyond the current hold point.
- No unresolved material issue remains.

### Fail When
- One or more material deficiencies prevent progression.
- The footing/foundation work is not ready for approval.

### Pending When
- Minor corrections or document clarifications are still outstanding but may be resolved promptly.

### Inspector Notes Guidance
Record the overall stage conclusion, major conditions reviewed, and the reason the stage is approved, failed, or held pending.

### Required Evidence / Documents
- Inspector-captured representative field photos sufficient to support the overall Stage 2 decision.

### Optional Evidence / Documents
- Summary video.
- Correction evidence.
- Supplemental note attachments.

### AHJ / Jurisdiction Notes
Capture any authority-specific release condition or pre-pour/pre-advance requirement tied to foundation stage approval.

---

## Stage Completion Rule
Structural Stage 2 is complete only when:
- all required containers are resolved,
- all required field evidence has been captured,
- no unresolved dependency remains,
- the footing/foundation stage has been approved, failed, or formally held with documented reasons.

## Stage Outcome
When Stage 2 is complete, the inspector has established:
- that the first field-stage structural conditions were reviewed,
- that the footing/foundation work was assessed against the approved project context,
- and that the project is either ready to advance, requires correction, or must be held/fail based on documented field evidence.
