# Lower Mainland property provider audit

Checked September 29, 2026. This document records the release boundary for Phase 3. `FULL` means the runtime can resolve the parcel and zoning and apply a reviewed municipal rule. `PARTIAL` means the runtime queries an official machine-readable zoning source, but the complete parcel conditions and current accessory-dwelling rules are not automated. `LOOKUP_ONLY` means the jurisdiction is automated and the municipal facts remain a human lookup. `SPECIAL_JURISDICTION` is always Yellow and never inherits a neighbouring municipality's rules.

The shared address source is the [Province of British Columbia Address Geocoder](https://digital.gov.bc.ca/bcgov-common-components/bc-address-geocoder/). Metro municipalities are distinguished with the [Metro Vancouver Administrative Boundaries layer](https://services1.arcgis.com/xeMpV7tU1t4KD3Ei/arcgis/rest/services/Administrative_Boundaries/FeatureServer/33). Reserve and treaty lands are checked before any municipal rule with the provincial [Indigenous Reserve Boundaries](https://services6.arcgis.com/yQl4SOjuM0Xu5UJ9/arcgis/rest/services/BC_Indigenous_Reserves/FeatureServer/2) and [First Nation Treaty Lands](https://services6.arcgis.com/yQl4SOjuM0Xu5UJ9/arcgis/rest/services/BC_FN_Treaty_Lands/FeatureServer/2) layers. Those special-land layers are used only to force a Yellow review; they are not presented as legal boundary determinations.

## Runtime rules

- Vancouver keeps the existing reviewed rules: `VAN-GREEN-R1-001`, `VAN-RED-STRATA-001`, `VAN-RED-COMMERCIAL-001`, `VAN-RED-INDUSTRIAL-001`, `VAN-YELLOW-CD1-001`, `VAN-YELLOW-PARCEL-001`, and `VAN-YELLOW-OTHER-001`.
- Every non-Vancouver municipal provider uses `REGIONAL-YELLOW-{JURISDICTION}-LOOKUP-001`. A `PARTIAL` provider reports the zoning returned by its official point query. A `LOOKUP_ONLY` provider confirms the jurisdiction without inventing a zoning district. Neither status invents property type, lot geometry, access, ALR, floodplain, watercourse or DPA facts.
- Electoral areas, Tsawwassen First Nation, reserve lands and treaty lands use `REGIONAL-YELLOW-{JURISDICTION}-SPECIAL-001`. The identified authority is included internally when the provincial boundary layer supplies it.
- Red is returned only by an authoritative implemented rule. A unit-like address in a Yellow-only municipality remains Yellow because address text alone is not property evidence.

## Resilience, freshness and service requirements

The government-data client uses a four-second timeout, one retry with exponential backoff, in-flight request coalescing, a bounded 500-entry cache, six-hour address/boundary caching, 24-hour reserve/treaty boundary caching, and a bounded 30-minute final-result cache. Failures are logged as structured provider-health events without the submitted address. A provider failure retains the lead and produces an internal Yellow result.

The live validation observed BC Address Geocoder API `4.5.4` with base data dated `2026-07-07T20:10:43Z`. The official developer guide states that anonymous access is available up to 1,000 requests per minute; an API key is needed only for higher sustained volume. No new paid service is required. A cold Metro lookup can make four official requests, so production volume and upstream 429/5xx health should be monitored even with caching.

## Validation evidence

`npm run qa:property-routing` checks a published civic checkpoint in all 31 registry routes against the live BC, Metro Vancouver, reserve and treaty endpoints. It also requires one official zoning match for each of the seven `PARTIAL` providers and validates the final provider status, jurisdiction, failure code and Green/Yellow lead state end to end. The same live run verifies `3193 Kitchener Street` as Green and `1288 Marinaside Crescent #106` as Red strata. Unit tests cover the registry routes, invalid inputs, simulated routing and zoning-provider failures, no-false-Red behavior, special-jurisdiction isolation, source-attribution guards, health-log privacy, Langley and North Vancouver boundary distinctions, UBC/UEL, FVRD, reserve precedence, ambiguity, retries, zoning conflicts and caching.

For Yellow-only jurisdictions, tests deliberately do not assert fabricated detached-property facts. The live `PARTIAL` checks validate official zoning for their published civic checkpoints; parcel-class and multi-zone eligibility fixtures should be added only as each municipality advances to `FULL` with verified official property records and dated rule sections.

## Email behavior

Customer Yellow example:

> **WE'RE TAKING A CLOSER LOOK**
> We found your property, but there are details that need to be reviewed before we make a recommendation. Nothing is required from you right now. Our team will review the property and determine the next step.

The internal email leads with municipality and jurisdiction, then records provider status, normalized property, available property facts, exact Yellow reason, rule ID, official URLs, checked timestamp, dataset/version metadata and confidence. Special-land results also name the identified authority where the boundary source provides it.
